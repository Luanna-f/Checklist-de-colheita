# Caderno de Campo do Vale — Checklist de colheita

App educacional em Flutter desenvolvido para a disciplina **Programação para Dispositivos Móveis** (IF Goiano, Campus Ceres).

Esta funcionalidade (**G. Checklist de colheita**) ajuda o produtor a acompanhar as tarefas antes e durante a colheita de soja e milho no Vale de São Patrício.

## O que o app faz

- Mostra uma lista de tarefas de colheita.
- Ao toque, marca ou desmarca cada item.
- Exibe o percentual concluído, atualizado a cada marcação.
- Permite adicionar itens próprios, com aviso de erro se o campo estiver vazio.

## Como rodar

Com o Flutter instalado, na pasta do projeto:

```bash
flutter create .
flutter pub get
flutter run
```

Depois do `flutter create .`, mantenha o `lib/main.dart` deste projeto (se o comando gerar um novo, substitua pelo nosso).
